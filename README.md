# mazos-aleman
Datos sincronizados de la app Léxico (mazos y resultados)

## Herramientas antiguas

`herramientas/` contiene el script que generaba las frases y los apartados de teoría, y su prueba.
Escribían en las rutas antiguas (`public/lex/…`) y en el formato anterior. Adáptalos a `decks/` y `teoria/` antes de volver a usarlos.
